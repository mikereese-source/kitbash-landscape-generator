## 1. Conclusions first: where we can win

1. **Nobody owns "terrain plus a finished shot plus the assets that go on it".** World Creator now has terrain,
   water, fog, clouds, scatter and an MCP server, but brings no asset library of its own (40+ plants and rocks). Kits
   are the one thing no terrain tool can copy. Lead with the shot, not the heightfield.
2. **Caves are a real gap.** No mainstream tool ships walk-in caves with formations. Only World Machine
   (Dragontail Peak) claims erosion that carves caves and underhangs, and Gaea and World Creator don't mention them.
   It's our clearest feature claim, if the result looks good.
3. **"No node graph" is a real angle but not unique.** True TERRAIN 5 (3,200+ sales) and World Creator 3's layers
   are already non-node. Our edge has to be *quality per click* (realism checks, good-looking bounds), not just
   fewer nodes.
4. **Price is not where we win.** Gaea Indie and World Creator Indie are $99 one-off; True TERRAIN is $59.99.
   Cargo is $59–79/month. We win by being *included* in Cargo, not by being cheap.
5. **AI/MCP is table stakes by launch.** World Creator 4 and TerrainForge already ship agent tools. Cargo MCP wins
   only if an agent can build terrain *and dress it with Kits* in one request; terrain-only MCP is a me-too.

## 4. Positioning: Mike's hypothesis, point by point

| Claim | Verdict | Evidence |
|---|---|---|
| **Fast and user-friendly, great quality without big node networks** | **Partly true** | Gaea, World Machine, Instant Terra, Houdini, TerrainForge and now WC4 are all node graphs, so "no graph" separates us from the leaders. But True TERRAIN 5 is one-click with 3,200+ sales, and World Creator 3 is layers. Our real edge is *the quality floor*: types checked against real elevation data and safe bounds so no slider combination looks bad. That isn't shown publicly yet. |
| **Lives in Cargo next to every Kit; build whole worlds with them automatically** | **True as a gap, not yet built** | No terrain tool owns an asset library: WC imports from Fab/Superhive/TurboSquid; Unreal has Fab/Megascans but a long workflow; Gaea and World Machine have none. Cargo's pricing page lists no terrain tool today. The claim depends on Kit scatter/placement that is still parked. |
| **Cargo MCP lets an AI client drive it** | **Partly: others got there first** | World Creator ships an MCP server that works on the open project; TerrainForge ships agent tools and skills ("a 4 km alpine valley with a lake"). Ours must be "terrain + Kits + camera" in one request to stand out. |
| **Gets to a finished, cinematic shot quickly: caves, water, fog** | **Not yet** | Caves: our strongest card; only World Machine claims cave carving. Water and fog: World Creator (fog, haze, volumetric clouds, water, renderer) and Terragen already do this well. Ours are planned (M7 water shaders, fog parked). Today our renders are not yet at their finish. |
| **KitBash-level quality bar** | **Unproven publicly** | We measure realism against real terrain (no competitor publishes that; TerrainForge shows one score). We need side-by-side shots against Gaea/WC renders before claiming it. |

**Who it's for:** KitBash's existing buyers: concept artists, matte painters, motion designers, film/TV previs, and
game environment artists who build *shots* with Kits and want ground, cliffs and a cave under them in minutes.
Cinema 4D users matter too (the GSG audience), which no Blender add-on reaches; the Cargo browser version can.

**Who it's not for:** terrain specialists building tiled, open-world game maps at 16K+ (Gaea Pro, World Machine,
Houdini, TerrainForge serve them better); people who want full node-level control; anyone wanting a cheap one-off
Blender add-on (True TERRAIN at $59.99 owns that).

## 5. Gaps and risks

**Must match before launch**
1. **Finished look out of the box:** auto-materials, water shaders, fog/haze and a sky. World Creator and Terragen
   set this bar; TerrainForge's flat-colour materials show what "not finished" looks like.
2. **Scatter, at least with Kits:** True TERRAIN ships 220+ assets, WC 40+, Botaniq pairs with anything. Without
   Kits on the ground, "build the world" is just a promise.
3. **Engine handoff:** Unreal (heightmap + paint layers + water) and a heightmap export; WC and Gaea already bridge
   to 4–6 apps. C4D matters for GSG customers.
4. **Real-world starting point:** every serious tool now imports real elevation; TerrainForge does it free with
   lidar. We have the data pipeline (realism checks) but no user feature.
5. **Resolution/speed in the browser:** competitors build 8K–16K. A browser tool must at least preview fast and
   hand off high-res to Blender/Unreal.

**What would undercut us**
- **World Creator 4** (Early Access since 2026-11-03): node graph, new simulation (water, sand, snow), path tracer,
  MCP, and $99 Indie. If it adds a big asset partner, the "assets next to terrain" gap narrows.
- **Gaea 3** adding Blender/Unity/Max plug-ins and ecosystems: brings its quality straight into Blender.
- **TerrainForge** free during preview with open-source agent tools: hard to compete on price for Unreal users.
- **AI world generators** (World Labs Marble, $20–95/month ⚠): text to a whole world in minutes. Lower control and
  quality today (mesh export takes ~1 hour, per its docs), but they own the "finished shot fast" message if we don't.
- **Megascans/Fab inside Unreal:** Epic can bundle terrain + scans for Unreal users at no extra tool cost.
- **Internal:** if the tool sits behind the $59–79/month Cargo plan only, hobbyists and Blender-only users compare
  it against $99 one-off tools.

## 6. Suggested positioning statement and proof points

> **The KitBash Landscape Generator gets you from empty scene to a finished landscape shot in minutes: pick a
> landscape, shape it with a few plain controls, add caves, water and fog, and build on it with every Kit in Cargo.
> No node graphs. Checked against real terrain, so it always looks real.**

Proof points we'd need to show:
1. **Speed:** a timed screen recording, empty scene to a lit, fogged shot with Kits placed, under 5 minutes (to be
   measured; no number exists yet).
2. **Quality:** 3–4 side-by-side stills against real photos of the same landform type (we already have references
   and realism scores) and against a Gaea/WC render of a similar scene.
3. **Caves:** a walk-in cave shot with formations and a flooded chamber, a camera moving inside. Nobody else shows
   this out of the box.
4. **Kits:** the same terrain dressed with two different Kits (e.g. a fantasy and a sci-fi Kit) in one click each.
5. **Agent:** one Cargo MCP prompt ("a desert canyon at dusk with a cave and the Wasteland Kit") producing the shot.

## Mike's answers (2026-11-06)
1. **Packaging and price in Cargo:** not now. First make something that looks good enough to go further into Cargo; talk packaging later.
2. **Kit placement or finished look first:** the finished look first (materials, fog, atmosphere: a terrain that looks done). Later, the MCP builds a terrain and places Kits in it; that complements the finished look.
3. **Real-world terrain at launch:** not decided. Focus on a really good-looking, finished terrain; then presets and templates artists can pick from, real-world or not (it doesn't matter which).
4. **Send-to-C4D:** there is a Cinema 4D MCP; whether this carries over is for later.
5. **Publish the realism score:** no. It's an internal bar, so the team can look at a result and say "wow, this looks very good".
6. **Track AI world tools:** question explained in chat (pending Mike's call).
